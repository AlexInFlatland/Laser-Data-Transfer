# Sending Binary Data Using Lasers

Arduino code for sending data over a laser beam. The sender pulses two lasers, one carrying a clock signal and one carrying the data. The receiver reads both back with photo-resistors.

- `Sender/Sender.ino`: code for the transmitting Arduino
- `Reciever/Reciever.ino`: code for the receiving Arduino
